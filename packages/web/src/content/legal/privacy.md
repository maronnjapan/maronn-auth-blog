# プライバシーポリシー

最終更新日: 2026年9月6日

Auth Vault（以下「当サイト」）における、アクセス情報の取り扱いについて説明します。

## 1. 当サイトについて

当サイトは運営者個人が執筆した記事を公開する静的なブログです。閲覧にあたってアカウント登録やログインは必要なく、当サイトが氏名・メールアドレスなどの個人情報を直接収集することはありません。

## 2. 収集する情報

### 2.1 アクセス情報

当サイトでは、サイト改善を目的として **Cloudflare Web Analytics** を使用する場合があります。

Cloudflare Web Analytics は Cookie を使用せず、個人を追跡しない分析サービスです。収集される情報には以下が含まれます。

- ページビュー数
- 訪問者数（匿名化）
- リファラー情報
- 国・地域情報
- ブラウザおよびデバイスの種類

これらは統計的な分析にのみ使用され、個人を特定することはできません。

### 2.2 配信基盤のログ

当サイトは Cloudflare 上で配信しています。配信および攻撃防御のため、Cloudflare がアクセスログを記録することがあります。詳細は [Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/) を参照してください。

## 3. 外部サービスの埋め込み

記事中に X（旧 Twitter）、GitHub、YouTube などのコンテンツを埋め込むことがあります。埋め込みコンテンツを表示する際、各サービスに対して通信が発生し、それぞれのサービスの規約とプライバシーポリシーが適用されます。

## 4. 第三者への提供

当サイトが取得した情報を第三者へ販売・提供することはありません。ただし、法令に基づく開示請求があった場合はこの限りではありません。

## 5. 本ポリシーの変更

本ポリシーは必要に応じて変更することがあります。変更した場合は、本ページの最終更新日を更新します。

## 6. お問い合わせ

当サイトに関するお問い合わせは、[GitHub リポジトリ](https://github.com/maronnjapan/maronn-auth-blog) の Issue からご連絡ください。
